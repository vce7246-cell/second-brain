# SecondBrain v2 — 界面链接 + 知识梳理 设计文档

> 版本: v0.1 | 日期: 2026-07-17 | 状态: 待评审

## 背景

当前 MVP 的三个核心问题：

1. **链接的唯一载体是 `[[]]` 语法嵌入原文**——不在笔记里写 `[[标题]]`，图谱和反向链接就是空的
2. **没有归纳梳理能力**——打开 sb 看到的只是文件树 + 编辑器，和 VS Code 没本质区别
3. **依赖手动文件夹分类**——sb 只是把文件夹结构"展示"出来，没有在笔记之上加一层知识视图

## 核心设计决策

### 决策 1: 链接数据外挂存储

**选型**: 集中索引文件 `.sb/links.json`

```
my-vault/
├── .sb/
│   ├── links.json       ← 所有链接关系 + 标签
│   └── config.json      ← 用户偏好
├── 笔记A.md             ← 原文完全不碰
└── 笔记B.md
```

**数据结构**:
```json
{
  "version": 1,
  "links": [
    { "from": "学习/TypeScript.md", "to": "学习/React.md" },
    { "from": "学习/TypeScript.md", "to": "项目/重构计划.md" }
  ],
  "tags": {
    "学习/TypeScript.md": ["前端", "类型系统"],
    "学习/React.md": ["前端", "框架"]
  }
}
```

**设计要点**:
- 链接是独立实体，不嵌入笔记原文和 frontmatter
- 双向自动推导：存 `A→B`，反向链接 `B←A` 自动算出
- 与已有 `[[]]` 内联链接共存——indexer 解析的 `[[]]` 链接和界面链接在 UI 中合并展示
- 单文件，查询 O(1)，容易备份

### 决策 2: 文件夹 → 自动分组

**原则**: 文件夹路径自动作为隐式标签，无需用户额外操作。

```
项目/重构/重构计划.md  →  自动标签: 📁 项目, 📁 重构
学习/TypeScript.md      →  自动标签: 📁 学习
```

- 文件夹标签和手动标签在 UI 中并列，图标区分（📁 vs 🏷️）
- 一篇笔记可以同时有文件夹标签（物理归属）和手动标签（主题分类）

### 决策 3: 保留现有 `[[]]` 支持

- 已在笔记中的 `[[标题]]` 继续生效，不做迁移
- indexer 解析的 inline 链接 + links.json 的界面链接合并展示
- 新用户可以不写一个 `[[]]`，老用户的笔记不受影响

## 功能规格

### F1: 界面链接管理系统

#### F1.1 链接面板 (Link Panel)

右侧面板新增"链接"区域，位于反向链接面板上方：

```
┌─────────────────────┐
│ 🔗 链接             │
│ ┌─────────────────┐ │
│ │ 搜索笔记...      │ │  ← 搜索框
│ └─────────────────┘ │
│                     │
│ 已链接:             │
│  ✕ React.md        │  ← 点击 × 删除链接
│  ✕ 重构计划.md      │
│                     │
│ + 添加链接          │  ← 弹出笔记选择器
└─────────────────────┘
```

- 搜索框支持模糊匹配笔记标题
- 添加/删除链接立即写入 `links.json`，WebSocket 广播更新
- 反向链接自动更新

#### F1.2 图谱拖拽连线

力导向图中，从一个节点拖拽到另一个节点 → 创建链接：

- 鼠标按下一节点 → 出现拖拽线跟随光标 → 释放到目标节点 → 链接创建
- 视觉反馈：释放前高亮目标节点
- 已有连线的两节点之间：点击连线显示"删除"按钮

#### F1.3 右键文件树链接

文件树中右键笔记 → "链接到..." → 弹出笔记选择器 → 选择目标

#### F1.4 未链接提及检测

当笔记 A 正文中出现笔记 B 的标题文本但两者无链接时，在反向链接面板显示：

```
反向链接
├── 🔗 已链接
│   └── 重构计划.md
└── 💡 未链接提及
    └── React.md  ← 正文中出现了"React"但未链接  [链接]
```

- 检测逻辑：对当前笔记标题做全文匹配（大小写不敏感），排除已有链接和自引用
- **可扩展**: V2 增加 TF-IDF 相似度检测，覆盖标题不匹配但内容相关的情况

#### F1.5 自动链接建议

后台用 TF-IDF 计算笔记间内容相似度，打开笔记时底部 toast：

> "发现 2 篇内容相似的笔记：React 进阶.md, 前端面试.md。要链接吗？[确认] [忽略]"

- 不强制，不自动创建链接
- 相似度阈值可配置，默认中等偏保守（避免噪音建议）

### F2: 标签系统

#### F2.1 手动标签

在链接面板中为笔记添加标签，数据存储在 `links.json` 的 `tags` 字段。

- 输入框支持逗号分隔批量添加
- 标签即时搜索过滤
- 删除标签：点击 `✕`

#### F2.2 文件夹自动标签

文件夹路径自动作为隐式标签，无需用户操作。

- 在标签视图和仪表盘中显示，图标为 📁
- 手动标签图标为 🏷️
- 不可手动删除文件夹标签（由文件系统路径决定）

#### F2.3 标签视图

左上角新增"标签"视图切换按钮：

```
标签                         过滤结果
──                          ──
📁 项目 (8)                 TypeScript.md
📁 学习 (12)                 React.md
🏷️ 前端 (15)                 重构计划.md
🏷️ 类型系统 (5)              ...
🏷️ 面试 (3)
```

- 点击标签过滤笔记列表
- 多选标签支持 AND 逻辑
- 标签旁数字 = 关联笔记数

### F3: 仪表盘

启动 sb 默认展示仪表盘（替代空白编辑器）：

```
┌────────────────────────────────────────────┐
│  📊 知识库概览                              │
│                                            │
│  32 篇笔记    58 条链接    8 个标签          │
│                                            │
│  🔥 核心节点（被链最多）                     │
│  ┌─ TypeScript.md       ← 12 篇           │
│  └─ 重构计划.md          ← 8 篇            │
│                                            │
│  🏝️ 孤立笔记（无任何链接）                   │
│  ┌─ 零散想法.md          [添加链接]         │
│  └─ 会议记录_0701.md     [添加链接]         │
│                                            │
│  📁 项目分组                               │
│  ┌─ 重构     2 篇 · 3 链接                 │
│  └─ 新产品   1 篇 · 🏝️                    │
│                                            │
│  📝 最近修改                               │
│  ┌─ React.md            · 2 小时前        │
│  └─ TypeScript.md       · 昨天            │
└────────────────────────────────────────────┘
```

### F4: 图谱增强

#### F4.1 全量图谱

- 现有功能保持
- 新增：按标签着色节点，同标签节点同色系
- 新增：孤岛节点灰色显示
- 新增：拖拽连线建链接（见 F1.2）

#### F4.2 局部图谱

打开一篇笔记时可选"局部图谱"——仅显示当前笔记的直接邻居（1~2 步）：

- 导航顶栏新增"局部图谱"按钮
- 点击后全屏展示局部力导向图
- 节点默认显示 1 步邻居，可通过滑块扩展到 2~3 步
- 中心节点高亮

---

### F5: 快速切换器

`Ctrl+O` 触发模糊搜索输入框：

```
┌─────────────────────────┐
│ > type                  │
│ ─────────────────────── │
│ TypeScript.md           │
│ TypeScript 泛型.md       │
│ TypeScript 装饰器.md     │
└─────────────────────────┘
```

- 模糊匹配笔记标题（简单 substring + Levenshtein 排序）
- 回车打开选中笔记
- 1px 边框 + 阴影浮层，不遮挡编辑器

---

### F6: 每日笔记

顶栏"每日笔记"按钮 → 创建 `yyyy-MM-dd.md` 到配置的目录（默认 `daily/`）→ 自动添加 `📅 日记` 标签。

- 如果当天笔记已存在，直接打开
- 支持配置目录路径（`.sb/config.json`）

## 非功能需求

- **链接数据持久化**: 每次界面操作（添加/删除链接、标签）立即写入 `links.json`，不使用 debounce
- **兼容性**: `.sb/links.json` 包含 `version` 字段，支持未来数据迁移
- **性能**: 1000 篇笔记 + 5000 条链接下，dashboard 加载 < 500ms
- **与 `[[]]` 共存**: indexer 解析的 inline 链接和 links.json 的界面链接在 API 层合并，前端无感知
