# SecondBrain Lite — 产品需求文档

> 版本: v0.2 | 日期: 2026-07-16 | 状态: 草稿

## 1. 项目愿景 (Vision)
- **一句话描述**: 一个基于本地 Markdown 文件的个人知识库，提供双向链接编辑和力导向图谱可视化。
- **目标用户**: 用 Markdown 记笔记、希望看到知识之间关联关系的个人用户（开发者、研究者、写作者）。
- **核心价值**: 你的笔记永远是纯 `.md` 文件——用任何编辑器都完整可读。`sb` 只是加了一层 Web 界面来写链接和看图谱。数据所有权完全在你手里。

## 2. 核心机制 / 功能 (Core Mechanics)
### 2.1 笔记编辑器
- **描述**: 在浏览器中编辑 Markdown 笔记，支持语法高亮和分屏实时预览。
- **用户故事**: 作为用户，我想要在浏览器中写 Markdown 笔记并实时看到渲染效果，以便编辑体验流畅。
- **交互流程**: 点击左侧文件树的某篇笔记 → 中间区域出现编辑器 → 右侧同步显示渲染后的 HTML 预览。编辑器支持 `[[` 触发自动补全。

### 2.2 Wikilink 双向链接
- **描述**: 在笔记中用 `[[笔记标题]]` 语法创建链接。每篇笔记展示其"出链"（我链接了谁）和"反向链接"（谁链接了我）。
- **用户故事**: 作为用户，我想要用 `[[` 快速链接到其他笔记，并在被引用笔记中看到"谁引用了我"，以便发现知识之间的隐藏关联。
- **交互流程**: 编辑器中输入 `[[` → 弹出笔记标题列表 → 选择目标 → 自动插入 `[[标题]]`。打开任意笔记时，右侧面板显示反向链接列表。

### 2.3 力导向知识图谱
- **描述**: 将所有笔记可视化为可拖拽的力导向图。笔记是节点，`[[链接]]` 是连线。可缩放、拖拽节点、点击跳转。
- **用户故事**: 作为用户，我想要看到所有笔记的全局关联视图，以便发现笔记簇和孤立笔记。
- **交互流程**: 点击顶部导航的"图谱" → 全屏显示 D3.js 力导向图 → 节点自动布局 → 拖拽节点调整位置 → 点击节点跳转到对应笔记。

### 2.4 文件树管理
- **描述**: 左侧边栏展示笔记库的目录结构，支持新建、删除、重命名笔记。
- **用户故事**: 作为用户，我想要浏览我的笔记目录并快速切换笔记。
- **交互流程**: 左侧显示文件夹树 → 点击展开/折叠 → 点击笔记文件名打开编辑 → 右键新建/删除/重命名。

### 2.5 图片粘贴插入
- **描述**: 在编辑器中粘贴图片（Ctrl+V）自动保存为原始格式文件到笔记目录，并插入 Markdown 图片语法。预览中正确渲染图片。
- **用户故事**: 作为用户，我想要直接从剪贴板粘贴图片到笔记中，图片以原始格式保存在本地，以便笔记图文并茂。
- **交互流程**: 在编辑器中 Ctrl+V 粘贴图片 → 自动生成 `yyyyMMddHHmmss.ext` 文件名 → 保存到 `笔记所在目录/images/` → 在光标位置插入 `![alt](images/filename.ext)` → 预览中实时渲染图片。

## 3. MVP 范围定义 (MVP Scope)
### 本次 MVP 包含
- [ ] CLI 启动命令 `sb start`（指定笔记目录，启动 Web 服务）
- [ ] 内建 Markdown 编辑器（CodeMirror 6，语法高亮 + `[[` 自动补全）
- [ ] 分屏实时 Markdown 预览（含 `![](path)` 图片渲染）
- [ ] Wikilink 解析引擎（`[[标题]]` / `[[标题|别名]]` 语法）
- [ ] 反向链接面板（当前笔记被哪些笔记引用）
- [ ] 力导向知识图谱（D3.js force simulation，可拖拽/缩放/点击跳转）
- [ ] 文件树侧边栏（浏览、新建、删除笔记）
- [ ] 图片剪贴板粘贴 + 自动保存原始格式 + 插入 `![](path)`
- [ ] 文件系统监听 + 浏览器热更新（外部编辑器修改后自动刷新）
- [ ] Frontmatter 解析（标题、标签字段）

### 明确的 "不做" (Out of Scope)
- ❌ 全文模糊搜索（V2，需引入 MiniSearch 或 Pagefind 索引引擎）
- ❌ 块级链接 `[[note#paragraph]]`（需要 Markdown AST 级别的解析）
- ❌ 标签聚合页（Frontmatter tags 字段先解析但不做 UI）
- ❌ 图片拖拽/批量上传（仅支持 Ctrl+V 粘贴单张）
- ❌ 插件系统
- ❌ 主题系统（V1 一个浅色主题）
- ❌ 多标签页/工作区
- ❌ Git 集成 / 版本历史
- ❌ 云同步 / 移动端

## 4. 非功能需求 (Non-Functional Requirements)
- **性能**: 1000 篇笔记以下，图谱渲染 < 2 秒，编辑器响应 < 100ms
- **兼容性**: 支持 Chrome/Edge/Firefox 最新两个大版本
- **安全**: 纯本地运行，无网络请求，无用户认证系统
- **可移植性**: 笔记库就是一个普通文件夹，复制到任何地方都能用

## 5. 约束与假设 (Constraints & Assumptions)
- 笔记以 `.md` 后缀的纯文本文件存储，UTF-8 编码
- 链接信息存储方式需在技术选型阶段确定（frontmatter 字段 vs 内联 `[[]]` 即时解析）
- 假设用户笔记库不超过 5000 篇（超过后需引入增量索引和虚拟滚动）
- CLI 只做一件事：解析参数 → 启动 HTTP 服务器 → 打开浏览器
- Node.js >= 18 运行环境
