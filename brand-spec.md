# SecondBrain Lite UI Brand Spec

## Identity

- Product name: `SecondBrain Lite`.
- Existing identity asset: text wordmark only. The repository does not contain a logo image, so the redesign preserves the real text wordmark and does not invent a symbol.
- Product promise: local-first personal knowledge workspace with Markdown as the durable source format.

## Selected Direction

- Direction: 温暖纸张编辑感（the third approved reference direction).
- Mode: Redesign · Preserve.
- Visual target: the `paper` variant in `SecondBrain UI Reference.html` created during the approved v0 design checkpoint.
- Product structure, navigation labels, data states, and interactions remain unchanged.

## Design Tokens

- Canvas: `#ded8cd`
- Application shell: `#f3eee4`
- Surface: `#f8f3e9`
- Reading paper: `#fffdf7`
- Muted surface: `#ebe4d8`
- Text: `#302c27`
- Muted text: `#746b60`
- Border: `#ddd3c4`
- Accent: `#9b4c34`
- Accent soft: `#f2e1d7`

## Typography

- Interface: local Chinese sans-serif system fonts.
- Reading and display: local Song-style serif fonts, with `SimSun` as the Windows fallback.
- Code and paths: local monospace system fonts.
- No network font requests or new font dependencies.

## UI Rules

- Prefer whitespace, alignment, and dividers over nested cards.
- Use small radii and restrained shadows; elevation is reserved for the application shell and overlays.
- File types use compact text labels such as `MD`, `PDF`, and `IMG`, not emoji or invented icons.
- Motion is limited to short hover and state transitions and respects reduced-motion preferences.
- Attachments continue to display only the capabilities actually supported by the product.

## Assets

- No illustration, photography, or product imagery is required for the current application UI.
- No new icon or image asset has been introduced.
